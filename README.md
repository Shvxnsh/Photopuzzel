# Photopuzzel

A playful photo puzzle and photobooth strip experience. Upload an image, take one with your camera, or use a studio sample. Click two tiles to swap them; solve the puzzle to unlock a downloadable three-frame photo strip.

## Run it

Open `index.html` in a browser, or serve the folder with any static server. Camera mode works on `localhost` or an HTTPS deployment because browsers require a secure context for camera access.

## Features

- Upload an image or capture one from the camera
- 2×2 through 4×4 clickable photo puzzles
- Visual progress, move count, correct-piece highlighting, and solved state
- Generated photobooth-style canvas strip
- Download PNG and print actions
